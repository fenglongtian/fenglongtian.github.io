智慧安防监控平台

面向园区 / 楼宇场景的可视化数据大屏，接入智能红外、烟感、防丢等设备，实时呈现点位状态，报警自动定位、视频联动并支持处理闭环。

Vue 3TypeScriptVitePinia EChartsLeafletWebSocketNode.js
▶ 在线预览（全屏大屏） 源代码仓库

项目背景

针对园区与楼宇内多类安防设备分散、报警响应不及时的问题，构建统一的监控指挥中心。 平台在地图上实时展示设备点位与状态，设备触发报警时自动定位、点位涟漪扩散并联动现场摄像头， 同时在大屏弹出报警事件，支持一键处理与恢复，形成"感知—预警—联动—处置"的完整闭环。

技术栈

  • 前端：Vue 3 + TypeScript + Vite + Pinia，ECharts 实现环形/柱状/折线发光图表，Leaflet 实现点位地图
  • 后端：Node.js + Express + ws，提供 REST 接口与 WebSocket 实时推送
  • 视觉特效：粒子连线背景、发光面板四角、报警涟漪、扫描线、数字滚动、等比缩放适配
  • 数据模式：默认内置模拟数据，无需后端即可完整演示；亦可切换为真实后端接口

核心功能闭环

  • 42 个设备点位按类型（红外/烟感/防丢）与状态（在线/离线/报警）分级渲染
  • 设备心跳、电量、在线状态实时更新，报警点位双层涟漪扩散并自动定位
  • 新报警居中弹窗（高危/普通区分），伴随提示音，6 秒自动关闭
  • 一键处理报警，设备恢复在线，事件状态实时同步
  • 现场视频联动面板，展示选中点位画面占位、坐标、电量与心跳信息
  • 核心 KPI 指标卡与在线/报警趋势图，等比缩放适配任意分辨率
